# Buildblazer Core

This is the common Typescript library for handling Buildblazer data.

Buildblazer is a tool for making and using character sheets for TTRPGs. You build up a character, milestone by milestone, then can add sheets using this build to play as this character! It supports automatic calculation of statistics in a flexible way, letting you fine-tune and automate your character without losing sight of what does what. Its flexibility is also designed for as extensive homebrew as you need. Buildblazer is the ultimate tool for keeping a character handy!

## Building the Library

```bash
npm run build
```

To ensure the program was built successfully, run:

```bash
npm run test
```
